# Montage intégré et repères sonores

Lecture automatique sans dialogue. Le profil musical suit l’horloge réelle des repères sonores ; pause et perte de focus suspendent les deux stems. Les commandes de jeu ne changent pas les images. Le bouton dédié passe le film entier. Les délais de mission restent suspendus.

L’introduction s’ouvre du noir sur deux secondes ; les autres apparitions durent 180 ms. La cloche et le réveil utilisent une coupe franche.
