# Une école possible — essai V3

Ouvrir **Voir-La-Fin-V3.html**, puis **Voir depuis le début**. Quatorze images, **69 secondes**. La position du son pilote l’image : pause et déplacements dans le morceau restent synchronisés.

Une nouvelle vignette de voiture relie l’invitation à la cour, de **19 à 25 s** : jeune professeur au volant d’une voiture neuve et propre, souriant et parlant ; vieux professeur au premier plan se frottant les yeux. Ses lunettes sont tenues dans l’autre main. Derrière le conducteur, l’aube éclaire un quartier résidentiel paisible. Aucun dialogue audible ni bulle.

Le bureau initial est plus pesant : pédale grave, mélodie abaissée d’une octave, pulsation lente et image sonore resserrée. Le trajet apporte une transition plus douce ; le thème lumineux repart à l’arrivée au campus. Le panorama reste le dernier plan du rêve, **56–62 s**. À **62 s**, musique et réverbération s’arrêtent. L’alarme plus sèche commence à **63,2 s**, avec le fauteuil et les papiers du réveil, dans une ambiance de pièce étroite et sans harmonie résiduelle.

Trois WAV : musique seule, repères seuls, montage complet. Instruments sources quantifiés en PCM 8 bits, quatre voies de musique ; alarme également rendue depuis un petit sample 8 bits. Le mix final est stéréo, 22 050 Hz / 16 bits. Le grave supplémentaire est original ; cloche, fauteuil et papiers viennent de la palette SFX du jeu. Partition et manifeste décrivent notes, sources et timings. Ce rendu ne prétend pas émuler exactement le matériel Amiga.

Reproduction : Python + NumPy, `tools/compose-cinematic-dream-v3.py`. Le script réutilise les outils V1/V2 sans écrire dans leurs dossiers. Les deux auditions précédentes restent disponibles. Guide du montage : **MONTAGE-V3.md**.

Cette V3 est une maquette isolée ; le jeu et GitHub Pages sont inchangés. Le trajet illustré du rêve n’est pas le quatrième trajet jouable vers Maison, toujours prévu pour plus tard.
