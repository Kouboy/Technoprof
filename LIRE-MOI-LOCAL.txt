TECHNOPROF — Physique appliquée
Version locale de playtest

1. Extraire le ZIP entier avant de lancer le jeu.
2. Dans le dossier Technoprof, ouvrir Jouer-Technoprof-Fenetre.html.
3. Cliquer sur « Ouvrir le jeu dans sa fenêtre », puis « Prendre le service ».
Sur Windows, Jouer.cmd ouvre aussi le lanceur. Si une fenêtre est bloquée,
choisir « Jouer dans cet onglet ». Le cadre reste en 4:3 au redimensionnement.

Le jeu fonctionne hors connexion, sans installation ni serveur.
Garder le dossier audio/ à côté des fichiers HTML pour entendre les musiques
et les cinématiques. Les réglages proposent quatre volumes séparés.

Trois affectations à réussir : Collège des Ormeaux, Lycée Auguste-Berthelot,
Lycée professionnel des Trois-Ponts. Le premier échec termine la tentative.

Commandes : flèches ou ZQSD ; Espace = saut ; F/X = frappe ou dialogue.
Souris et toucher directement dans la scène. Commandes et réglages sont dans
le menu ; P ou Échap suspend le jeu. Sur téléphone, le paysage est conseillé.

Manette standard Xbox : appuyer sur un bouton pour la détecter.
Stick gauche ou croix = diriger ; RT = accélérer ; LT = freiner.
À pied : A = saut ; B = frappe / dialogue ; haut/bas = portes et escaliers.
Start = commencer au titre, passer un film, pause / reprise en jeu.
Menus : A = valider, B = retour, gauche/droite = ajuster les volumes.
Une déconnexion suspend la partie ; reconnecter puis appuyer sur Start.

Après l'essai : Pause / aide > Exporter mon essai sauvegarde un journal JSON.
Le questionnaire RETOURS-TEST.txt aide à noter les retours. Rien n'est transmis
automatiquement. BUILD-INFO.json identifie la version et ses fichiers.
